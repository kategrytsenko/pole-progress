# Continue existing work

Read the project rules and `docs/ROADMAP.md` first.

Inspect the current Git diff, relevant files, recent changes and existing tests. Determine what was completed, what remains, and whether the previous approach still matches the codebase.

Do not redo completed work or overwrite unrelated changes.

Continue with the smallest next step. Run relevant tests, update `docs/ROADMAP.md` if the task changes feature status, and finish with a concise summary of changes, test results and outstanding work.
